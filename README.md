# Vite - 간단한 텍스트 에디터

vi 에디터를 본떠 만든 크로스 플랫폼 텍스트 에디터입니다. Windows, macOS, Linux에서 동작합니다.

## 기능

- **텍스트 편집**: 문자 입력, 삭제, 줄바꿈 지원
- **커서 이동**: 방향키로 커서 이동, Home/End 키 지원
- **파일 작업**: 파일 열기, 저장 기능
- **검색 기능**: Ctrl-F로 텍스트 검색 및 하이라이트
- **크로스 플랫폼**: Windows, macOS, Linux 지원

## 빌드 방법

### Makefile 사용 (권장)

```bash
make
```

빌드된 파일 정리:

```bash
make clean
```

### 수동 컴파일

#### Windows

```bash
gcc -Wall -Wextra -Werror -o vite.exe vite.c terminal.c editor.c display.c file_io.c
```

#### macOS / Linux

```bash
gcc -Wall -Wextra -Werror -o vite vite.c terminal.c editor.c display.c file_io.c
```

## 프로젝트 구조

프로젝트는 다음과 같이 모듈화되어 있습니다:

- `vite.h` - 헤더 파일 (상수, 구조체, 함수 선언)
- `vite.c` - 메인 함수 및 이벤트 루프
- `terminal.c` - 터미널 제어 함수들 (커서 이동, 입력 처리 등)
- `editor.c` - 에디터 핵심 로직 (텍스트 편집, 노드 관리)
- `display.c` - 화면 출력 관련 함수들 (상태 바, 텍스트 표시)
- `file_io.c` - 파일 입출력 함수들 (파일 읽기/쓰기, 검색)

## 사용법

### 새 파일 편집

```bash
./vite
```

또는

```bash
./vite.exe
```

### 기존 파일 열기

```bash
./vite filename.txt
```

## 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl-S` | 파일 저장 |
| `Ctrl-Q` | 종료 (두 번 눌러야 함) |
| `Ctrl-F` | 텍스트 검색 |
| `↑↓←→` | 커서 이동 |
| `Home` | 줄의 시작으로 이동 |
| `End` | 줄의 끝으로 이동 |
| `Backspace` | 문자 삭제 |
| `Enter` | 새 줄 삽입 |

## 상태 바

화면 하단에 상태 바가 표시되며 다음 정보를 보여줍니다:
- 파일명 (또는 "[No Name]")
- 총 줄 수
- 현재 커서 위치 (줄/총 줄)

## 제한사항

- 최대 파일명 길이: 100자
- 최대 검색어 길이: 100자
- 한 줄 최대 길이: 100,000자

## 개발 정보

이 프로젝트는 고급 자료구조 과제로 제작되었습니다.

### 주요 개선사항

- **모듈화**: 단일 파일을 여러 모듈로 분리 (터미널, 에디터, 디스플레이, 파일 I/O)
- **구조화**: 전역 변수를 구조체로 캡슐화하여 상태 관리 개선
- **함수 분리**: 긴 함수들을 작은 단위로 분리하고 중복 코드 제거
- **명확성**: 명확한 함수명과 상수 정의
- **메모리 관리**: 메모리 할당/해제 개선
- **가독성**: 코드 가독성 및 유지보수성 향상
